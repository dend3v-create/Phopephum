# ⚙️ DEVELOPMENT RULES

# ALWAYS

* ใช้ TypeScript strict
* ใช้ async/await
* แยก business logic เข้า packages/
* แยก types/shared
* Mobile-first เสมอ
* Log behavior ทุก feature สำคัญ
* Responsive ทุกหน้า
* Accessibility พื้นฐาน
* Optimize Edge Runtime

---

# NEVER

* ห้าม hardcode secret
* ห้าม expose engine
* ห้าม giant component
* ห้าม any type มั่ว
* ห้ามใช้ service_role ฝั่ง client
* ห้ามเรียก AI API จาก frontend

---

# 🔐 SECURITY RULES

## Required

* เปิด RLS ทุก table
* Validate input ทุก API
* Rate limit AI endpoints
* ใช้ Worker Proxy สำหรับ AI
* .env.local อยู่ใน gitignore

# 🗄️ DATABASE RULES

ทุก table ต้องมี:

```sql
created_at timestamptz default now()
updated_at timestamptz default now()
```

เปิด RLS เสมอ:

```sql
alter table profiles enable row level security;
```
