01

เลือก Approach การพัฒนา

⚛️
React Native
Expo + TypeScript
เขียนโค้ดครั้งเดียว รันได้ทั้ง iOS + Android ชุมชนใหญ่ มี Library ครบ
✅ Cross-platform ประหยัดต้นทุน ✅ Performance ดีมาก ✅ เชื่อม Next.js Backend ง่าย ⚠️ บาง Native Feature ต้อง Bridge
🔷
React Native + Expo
Expo Router + EAS Build
ใช้ Expo EAS Build ส่งขึ้น Store ได้ตรง มี OTA Update โดยไม่ต้อง Re-submit
✅ Deploy Store ง่ายที่สุด ✅ OTA Update ไม่ผ่าน Review ✅ Shared Code กับ Next.js ได้ ✅ Expo SDK ครบทุก Feature
⚡
Flutter
Dart + Material 3
ของ Google UI สวยมาก Performance ดี แต่ต้องเรียนภาษาใหม่ (Dart)
✅ UI/UX สวยงามมาก ✅ Performance ใกล้ Native ⚠️ ต้องใช้ Dart (Learning curve) ⚠️ ต้นทุนสูงกว่า
💡 ครูเด่นแนะนำ: เลือก React Native + Expo (EAS Build) เพราะ Backend เราใช้ Next.js อยู่แล้ว ทีม Dev ใช้ JavaScript/TypeScript เดียวกัน ลดต้นทุนได้ 30–40% เมื่อเทียบกับทำแยก Native 2 แอป และ Expo EAS ส่งขึ้น Store ได้ตรงโดยไม่ต้องมี Mac เองก็ได้

ขั้นตอนส่งขึ้น Store จริง

🤖
Google Play Store
ค่าสมัคร $25 (ครั้งเดียวตลอดชีพ)
1
สมัคร Google Play Console — play.google.com/console จ่าย $25 ครั้งเดียว
2
สร้าง App Listing — ชื่อ, คำอธิบาย (EN+TH), Category, Content Rating
3
อัปโหลด Assets — Icon 512px, Feature Graphic 1024×500, Screenshots 5+ ภาพ
4
EAS Build Android — eas build --platform android → ได้ .aab file
5
Internal/Beta Testing — เทสกับ 20 คนก่อน ผ่าน Google Play Internal
6
Submit for Review — รอ 1–7 วัน ผ่านแล้วขึ้น Production
Commission Google เก็บ 15% (ยอดแรก ฿875K/ปี) / 30%
🍎
Apple App Store
ค่าสมัคร $99/ปี ≈ ฿3,500/ปี
1
สมัคร Apple Developer Program — developer.apple.com จ่าย $99/ปี
2
สร้าง App ID + Provisioning — ใน Xcode / App Store Connect
3
สร้าง App Listing ใน App Store Connect — ชื่อ, คำอธิบาย, Screenshots ทุก Device
4
EAS Build iOS — eas build --platform ios → ได้ .ipa file (ไม่ต้องมี Mac!)
5
TestFlight Beta — ส่ง 100 Tester ทดสอบก่อน Launch จริง
6
Submit for App Review — Apple Review 1–3 วัน (อาจมี Rejection ครั้งแรก ปกติ)
Commission Apple เก็บ 15% (ยอดแรก $1M/ปี) / 30%
⚠️ ข้อสำคัญ App Store (iOS): Apple บังคับให้ Subscription ทุกอย่างในแอปต้องใช้ In-App Purchase เท่านั้น (ไม่ให้ link ออกไปชำระเงินข้างนอก) และเก็บ 15–30% Commission ดังนั้นต้องตั้งราคาให้บวก Commission ของ Apple ไว้แล้ว เช่น ต้องการรายได้สุทธิ ฿99 → ตั้งราคาใน Store ที่ ฿120–135
