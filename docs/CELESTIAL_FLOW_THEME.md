# Celestial Flow theme

Pho pe Phum keeps its navy and gold identity, with quiet moonlight, mint,
coral and violet accents inspired by the supplied astrology app references.
The crescent and orbital lines are decorative SVG, not a calculated lunar phase.

The shared public/member atmosphere, homepage illustration, daily guidance
cards, member navigation and horoscope topic buttons use the same palette.
Light mode uses ivory surfaces and darker accent text; mobile guidance cards
become single-column rows. Topic buttons have 44px minimum targets and a
visible keyboard focus ring. Decorative art respects forced-colors mode and
hover transitions respect reduced-motion preferences.

No authentication, calculation engine, subject data or score logic changes.
Guest/member navigation rules and the birthplace update fix remain intact.

Validation: TypeScript, existing active-subject regression suite, production
build, CI and public preview in both themes. Authenticated real-device mobile
validation requires a member session and is not claimed by these checks.
