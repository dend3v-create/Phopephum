ข้อมูลเกี่ยวกับการเขียนโค้ดโปรแกรมมิ่งเพื่อจัดรูปแบบเวลาในข้อนี้ **ไม่ได้มีระบุไว้ในเอกสารแหล่งข้อมูลที่คุณให้มา** (ซึ่งเน้นไปที่ทฤษฎีสถิติและการพยากรณ์เชิงธุรกิจ) แต่ผมได้ทำการประมวลผลและเขียนลอจิก (Logic) ขึ้นมาใหม่ โดยอิงจาก **ประวัติการสนทนาของเราและรูปแบบเวลาที่ปรากฏบนภาพผังดวงยามพรายกระซิบ** ซึ่งท่านอาจต้องตรวจสอบและปรับแต่งให้เข้ากับภาษาโปรแกรมที่ใช้ในแอปพลิเคชันของท่านอีกครั้งครับ

จากประวัติการสนทนาและภาพผังดวงยาม จะสังเกตเห็นว่าการแสดงผลเวลา 7 นาที 30 วินาที จะไม่ได้เขียนในรูปแบบมาตรฐาน `HH:mm:ss` (เช่น 06:07:30) แต่จะใช้รูปแบบทศนิยมย่อคือ **"06.07.5"** และหากเป็นเวลาที่ลงตัวพอดีจะเขียนเป็น **"06.15"** 

ดังนั้น ขั้นตอนการเขียนฟังก์ชัน `formatTime` เพื่อแปลง "จำนวนวินาทีรวม" ให้แสดงผลเป็นสตริง (String) ตามรูปแบบหน้าปัดผังดวงยามอย่างแม่นยำ มีขั้นตอนดังนี้ครับ:

### **ขั้นตอนการเขียนฟังก์ชัน `formatTime`**

**1. คำนวณแยกชั่วโมง นาที และวินาที ออกจากวินาทีรวม**
ใช้การหารปัดเศษลง (Floor) และการหารเอาเศษ (Modulo) เพื่อแยกหน่วยเวลา
*   **ชั่วโมง (Hours):** นำวินาทีรวมหารด้วย 3600 แล้วนำเศษจากการหาร 24 เพื่อป้องกันเวลาเกินเที่ยงคืน (24:00 น.)
*   **นาที (Minutes):** นำเศษของวินาทีที่เหลือจากชั่วโมง มาหารด้วย 60
*   **วินาที (Seconds):** นำวินาทีรวมมาหารเอาเศษด้วย 60 (ผลลัพธ์จะเป็น 0 หรือ 30 เสมอ เพราะเราบวกทีละ 450 วินาที)

**2. เติมเลขศูนย์นำหน้า (Zero Padding)**
หากชั่วโมงหรือนาทีเป็นเลขหลักเดียว (เช่น 6 หรือ 7) ต้องเติม '0' ด้านหน้าให้เป็นสองหลักเสมอ (เช่น '06', '07') เพื่อให้กราฟิกบนหน้าเว็บดูเป็นระเบียบ

**3. แปลงวินาทีให้เป็นเศษทศนิยม ".5"**
สร้างเงื่อนไข (If-Condition) ตรวจสอบว่าค่าวินาทีเท่ากับ 30 หรือไม่ 
*   ถ้าเท่ากับ 30 ให้แสดงผลเป็นสตริง **".5"**
*   ถ้าเป็น 0 ไม่ต้องแสดงผลอะไร

**4. นำมารวมกันเป็นผลลัพธ์ (String Concatenation)**
นำตัวแปรทั้งหมดมาต่อกันในรูปแบบ `ชั่วโมง.นาที + ทศนิยมวินาที + น.`

### **ตัวอย่างการเขียนโค้ด (JavaScript / TypeScript)**

คุณสามารถนำฟังก์ชันด้านล่างนี้ไปใช้งานในเว็บแอปพลิเคชันของคุณได้ทันทีครับ:

```javascript
function formatTime(totalSeconds) {
    // 1. ป้องกันกรณีเวลาเกิน 24 ชั่วโมง (วนลูปกลับไปเป็น 00:00)
    totalSeconds = totalSeconds % (24 * 3600);

    // 2. คำนวณชั่วโมง นาที และวินาที
    let hours = Math.floor(totalSeconds / 3600);
    let minutes = Math.floor((totalSeconds % 3600) / 60);
    let seconds = totalSeconds % 60;

    // 3. จัดรูปแบบตัวเลขให้มีเลข 0 นำหน้าเสมอ (เช่น 6 -> "06")
    let strHours = hours.toString().padStart(2, '0');
    let strMinutes = minutes.toString().padStart(2, '0');

    // 4. จัดรูปแบบวินาทีตามหน้าปัดดวงยาม (ถ้าเป็น 30 วินาที ให้เติม .5)
    let strSeconds = "";
    if (seconds === 30) {
        strSeconds = ".5";
    }

    // 5. นำตัวแปรมาต่อกัน
    return `${strHours}.${strMinutes}${strSeconds}น.`;
}

// ---------------------------------------------------------
// ตัวอย่างการจำลองการเดินเวลา 12 ช่อง (ช่องละ 7.5 นาที หรือ 450 วินาที)
// อิงจาก ยาม ๑ กลางวัน (เริ่ม 06:00 น.)
// ---------------------------------------------------------
let startSeconds = (6 * 3600) + (0 * 60); // เริ่มที่ 06:00 น. (21,600 วินาที)
let slotDuration = 450; // 7.5 นาที = 450 วินาที

console.log("ตัวอย่างการลงเวลา 12 ช่อง:");
for (let i = 0; i < 12; i++) {
    let currentSlotSeconds = startSeconds + (i * slotDuration);
    console.log(`ช่องที่ ${i + 1}: ${formatTime(currentSlotSeconds)}`);
}
```
